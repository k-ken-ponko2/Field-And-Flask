ブラウザで動く Godot ビルド（Web 書き出し）、設計用の HTML プロトタイプ、実機スクショ、ドット絵スプライトの一覧。 最新のコミットから GitHub Actions が自動でビルドしている。

Godot のビルドは初回に約 45MB を読み込む。読み込み中は黒い画面にプログレスバーが出る。 音は出ない。キーボード操作のシーン（採取マップ）はキャンバスをクリックしてから操作する。

1 ブラウザで遊ぶ（Godot Web ビルド）

作業台 — 道具をドラッグ＆ドロップ
熱源（直火／囲い炉／ふいご炉）を据え、その上に土器やるつぼを置く。容器は火の温度に追従し、耐熱を超えるとひびが入る。
右のパレットから左へドラッグ＆ドロップ。熱源 → 容器の順。火の操作は据えた熱源のもの（クリック／スライド／長押し）。
開く
火ラボ ① 直火 — 天井 600℃
石で囲った焚き火。タイミングよく薪を入れる。
火の上をクリック。燃料ゲージの枠内（熾火）でドットの輪が回ったときが好機。
開く
火ラボ ② 囲い炉 — 天井 900℃
土の囲いと煙突。うちわであおぐ。
火の上でマウスを左右に動かす。手を止めると火勢が落ちる。
開く
火ラボ ③ ふいご炉 — 天井 1300℃
粘土のドーム炉と羽口。ふいごを踏み続ける。
火の上でクリックを押し続ける。短い押下では弱い。
開く
反応マップ — 温度 × 濃度 / pH
酸・塩基系マップ。加熱／加水／蒸留／中和／素材投入でマーカーを動かし、目標領域へ。
右のボタンで操作。暴走域に入るとバッチ全損。
開く
採取マップ
手続き生成の草原を歩く。木や岩との衝突、カメラ追従。
キャンバスをクリックしてから WASD / 矢印キー で移動。
開く
デバッグメニュー
全シーンを一覧から開く。各シーンの左上「← メニュー」で戻れる。
URL に ?scene=<id> を付けると直接開く（id: lab_bench / fire_lab_direct / fire_lab_fan / fire_lab_bellows / fire_lab / reaction_lab / field）。
開く
