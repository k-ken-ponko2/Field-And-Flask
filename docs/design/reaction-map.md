# 反応マップ 詳細設計

> 本作の核心（設計書 §3）。コンセプト設計書 §10 の3つの論点をここで確定し、`core/reactions/` の実装に対応させる。

---

## 決定サマリ

| 項目 | 決定 |
|---|---|
| 軸 | **温度（縦）× 濃度（横）** の 2D 連続平面 |
| pH | **連続値の等高線オーバーレイ**（移動軸ではない。組成＋濃度から算出される“結果”） |
| 操作モデル | **離散工程の積み重ね**（1操作＝1ステップ、各操作は量を持つ） |
| 失敗ペナルティ | **素材ロス＋設備耐久**（かすり→減収 / 突入→全損 / 深部→設備ダメージ）。キャラ負傷なし |
| 目標到達 | **領域内に入れば即成功**（座標条件＋任意の pH 条件） |

## 1. 3つの操作レバー

移動軸は温度×濃度の2つだが、**中和**を加えて実質3レバーになる。

| 操作 | 効果 | 実装 |
|---|---|---|
| 加熱／冷却 | 温度（縦）を上下 | `heat(amount)` |
| 加水（希釈） | 濃度（横）を下げる＝左へ。pH も中性へ寄る | `add_water(amount)` |
| 蒸留 | 濃度を上げる＝右へ。収率が落ちる | `distill(amount)` |
| 酸／塩基の投入 | 組成 `net_acid` を動かす＝中和。マーカーは動かさない | `add_acid` / `add_base` |
| 素材投入 | 固有方向へ跳躍し、素材の酸性度を組成へ加える | `add_material(def)` |

---

## 2. pH の連続モデル（`ph_model.gd`）

pH は直接設定する値ではなく、**組成・濃度・温度から算出される結果**。等高線として描くための数値核。

```
a  = net_acid × 濃度(0..1) × ACIDITY_GAIN
中性点 = 7 − TEMP_NEUTRAL_SHIFT × (温度(0..1) − 0.5)
pH = 中性点 − 7 × tanh(a)   （0〜14 にクランプ）
```

この式ひとつで、狙った3つの挙動が全て出る：

- **希釈で中性へ**：濃度→0 なら a→0 ＝ pH→中性点
- **中和で中性へ**：`net_acid`→0 なら pH→中性点
- **強酸・高濃度で低 pH**：a が大きく tanh が飽和 → pH→0 付近
- **高温で中性点がわずかに低下**（Kw の擬似表現、フレーバー）

`tanh` により特異点なく 0〜14 に収まるので、等高線描画に向く。**組成（`net_acid`）が変わるたびに等高線群を引き直す**のが視覚の肝（塩基を足すと等高線が横滑りし、マーカーが赤→緑へ入る＝中和が一目でわかる）。

入力の濃度・温度は「マップ座標を 0〜1 に正規化した値」を使い、軸の絶対単位に依存しない。

## 3. 領域（`reaction_region.gd`）

円（中心＋半径）で表現。目標・暴走・未踏の3種。目標と暴走域は **座標条件に加えて任意の pH 条件**を持てる。

- `requires_ph = true` のとき、領域は空間的に含むだけでなく pH が `[ph_min, ph_max]` に入る必要がある
- 例）希硫酸の目標領域：`center=(2,6)`, `radius=1.2`, `ph_min=0`, `ph_max=3`
  → 指定座標へ到達し、かつ十分に酸性でなければ得られない

到達判定は `ReactionSim.reached_target()` が「座標 `contains` かつ `accepts_ph`」の両方を満たす目標を返す。

## 4. 収率＝経路効率（`reaction_sim.gd`）

「上手い経路ほど高収率」（§3.3）を数値化する。

```
効率 = clamp(最短直線距離 / 実経路長, 0, 1)
収率 = 効率^YIELD_EXPONENT − 蒸留ペナルティ − 暴走域ペナルティ
```

- まっすぐ目標中心へ到達 → 効率 1 → 収率ほぼ 1
- 蛇行・遠回り → 実経路長が伸びて効率低下
- `YIELD_EXPONENT`（既定 1.5）で「最短がどれだけ有利か」を調整
- 目標領域の外にいる試行中は、素朴な `1/(1+経路長×係数)` を目安に表示

---

## 5. 暴走・失敗のペナルティ

キャラ負傷は入れない（§6 のテンポ原則）。実験室は“安全な思考ゾーン”に徹する。

| 状況 | 判定 | ペナルティ |
|---|---|---|
| 縁をかすめる | 半径＋`HAZARD_GRAZE_MARGIN` の内側 | 収率減（縁に近いほど大） |
| 突入 | 半径の内側 | `batch_lost = true`（そのバッチ全損、収率 0） |
| 深部で突入 | 突入かつ 正規化温度 ≥ `HAZARD_DEEP_TEMP` | 上記＋`equipment_damage`（設備の修理素材が必要） |

## 6. 調整パラメータ一覧（`reaction_sim.gd` / `ph_model.gd` の定数）

| 定数 | 意味 | 既定 |
|---|---|---|
| `ACIDITY_GAIN` | 酸性度 → pH スケールのゲイン | 2.0 |
| `TEMP_NEUTRAL_SHIFT` | 温度による中性点の移動量 | 0.8 |
| `YIELD_EXPONENT` | 最短経路の有利さ | 1.5 |
| `DISTILL_PENALTY` | 蒸留1単位の減収 | 0.1 |
| `HAZARD_GRAZE_MARGIN` | かすり判定の余白 | 1.0 |
| `HAZARD_GRAZE_PENALTY` | かすりの最大減収 | 0.4 |
| `HAZARD_DEEP_TEMP` | 設備が痛む深部の温度閾値 | 0.7 |
| `HAZARD_EQUIP_DAMAGE` | 深部突入の設備ダメージ | 0.5 |

これらは `core/__tests__/run_tests.gd` でヘッドレス検証される（UI を起動せず化学を固定できる、設計書 §8）。
