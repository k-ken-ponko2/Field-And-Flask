# 熱源ツリー（温度の4段階）

> 設計書 §2 の「制約解除⑥」が、温度そのものに効く形。
> 反応マップは縦軸が温度なので、熱源ティア＝**温度軸の到達“天井”**。天井が上がると
> 上位の目標（土器→金属→鉄・ガラス）に手が届き、同じ温度に達するのも段々楽になる。

---

## 1. 4段階

| 段階 | 温度目安 | 必要なもの | 何ができるか |
|---|---|---|---|
| **① 直火** | 〜600℃ | 薪・地面 | 調理・乾燥・燻製・木炭作り |
| **② 囲い＋自然通風** | 700〜900℃ | 土/石の囲い・煙突（上昇気流） | 土器焼成・石灰焼き・鉛/スズ溶解 |
| **③ 送風＋木炭** | 1000〜1300℃ | ふいご・木炭・粘土の炉体・るつぼ | 銅・青銅・銀・金・鍛冶・陶磁器 |
| **④ 耐火煉瓦＋強制送風** | 1400〜1600℃ | コークス・耐火煉瓦・送風機・断熱層 | 製鉄・鋳鉄・ガラス溶融・セメント焼成 |

---

## 2. 「段々楽になる」＝3つの効き方

1. **到達↑**：温度の天井が上がる（上位目標・新マップの解禁トリガ）。
2. **燃費↓**：同じ温度に少ない燃料・短時間で到達（**本番生産／委任量産のコストが下がる**）。
3. **安定↑**：暴走域が縮む（オーバーシュートしにくく、かすり/全損の危険マージンが広がる）。

> 燃費・時間の差は**本番生産**で効かせる。実験レイヤは今まで通り時間ゼロ（§6）。

---

## 3. 一方通行の階段（依存関係）

```
① 直火で 木炭            → ②③の燃料に
② 囲い炉で 土器・るつぼ・石灰 → ③の炉材／反応素材に
③ 送風炉で 金属・耐火粘土   → ④の送風機部品・耐火煉瓦に
④ 耐火炉で 鉄・ガラス・セメント
```

**循環フック**：石灰焼き(②)→ 石灰＝反応マップの塩基素材／木炭(①)→ ③④の燃料／金属(③)→ ④の送風機。
「作った熱が次の物を、作った物が次の熱を可能にする」円環。

---

## 4. タクタイル入力：送風＝「あおぐ」

火力を上げる操作は**タクタイル**（`docs/design/tactile-crafting.md` の「あおぐ」原型）。

- **① 素手であおぐ**：マウス往復＝送風。疲れる・天井低い（`docs/prototypes/fanning.html`）。
- **③ ふいご**：押して送風（クリック/リズム）。一押しが大きい。
- **④ 送風機**：レバーで自動。あおぐ操作が不要になる＝「段々楽」の到達点。

つまりティアを上げるほど、**あおぐという手仕事が自動化**される。

---

## 5. データモデル案（小改修で実装可）

```
HeatSource (Resource, ①〜④)
  id / display_name / tier
  max_temperature   … 温度軸の天井。ReactionSim.heat() をここでクランプ
  heat_efficiency   … 本番生産の燃料・時間コスト係数（低=楽）
  stability         … 暴走域マージンのボーナス（高=安全）
  tech_id           … 解禁条件。recipe_book の依存で下位ティアを要求
```

- `ReactionSim` に `heat_ceiling` を持たせ、`heat()` を `min(マップ天井, 熱源天井)` でクランプ。
- ティアの階段は既存の **レシピ逆算（`recipe_book`）** がそのまま扱える。
- **天井はハード**（それ以上は上げられない）＝「新しい炉を作らないと届かない」を明快に。
