## 1. Potion Craft との対応

| Potion Craft | 本作（錬金ラボ） | ロジック側 |
|---|---|---|
| 錬金マップ（羊皮紙） | 反応マップ（温度×濃度、pH は色） | `ReactionMap` / `ReactionSim` |
| 材料を釜へドラッグ → 点線の経路が出る | 素材を釜へドラッグ。**かざした時点で点線の予告**、落とすと経路が確定 | `queue_material()` / `pending_points()` |
| スプーンでかき混ぜる → 経路に沿って進む | **かき混ぜ棒を掴み、釜の中で円を描く**と経路を進む（1周＝1.5 単位） | `stir(distance)` |
| ひしゃくで水 → 中心へ戻る | **ひしゃくを釜の上で保持**すると加水（左へ、pH は中性へ） | `add_water()` |
| （なし） | **蒸留器を釜の上で保持**すると蒸留（右へ、収率が落ちる） | `distill()` |
| ふいごで加熱 → 効果を発現 | **据えた熱源の操作**（薪クリック／あおぐ／ふいご長押し）。**釜の温度がそのまま縦軸** | `FireSim` + `LabBench` → `heat(dy)` |
| 瓶に詰めて完成 | **瓶を掴んで釜にかざす**。目標領域＋pH を満たしていれば瓶詰め、ノートに記録 | `reached_target()` / `to_note()` |
| レシピ本 | ノート（画面下の一行。保存・再生は `ReactionNote`） | `ReactionNote.replay()` |

Potion Craft に無いが本作にあるもの: **暴走域**（入ると全損。釜の中身が黒ずむ）、**熱源の天井**（マップに点線で「この炉の天井」）、**釜のひび**（耐熱超過で中身を失う）。
霧（未踏領域）は Potion Craft と同じ（§3）。

## 3. モヤ（霧）と発見

Potion Craft の霧と同じ約束を `core/reactions/map_exploration.gd`（`MapExploration`）で持つ。

- マップは最初モヤで覆われ、**マーカーが通った周り（半径 0.9）だけ晴れる**。晴れた跡はバッチをまたいで残る。
- 目標は晴れても**「？」のまま**。到達中の読み出しも「未知の物質（瓶詰めで判明）」。
- **瓶詰めの条件**: 目標の円の中にいること ＋ **円の内側のモヤが半分以上晴れている**こと（`clear_ratio ≥ 0.5`）＋ pH 条件。
  霧が濃ければ「霧が濃くてまだ見えない…（xx% / 50%）」、pH が外れていれば「円の中だが pH が条件外」と断る。
  目標の輪は晴れ具合で濃くなり、半分を超えると金色になる（＝瓶詰めできる合図）。
- **瓶詰め（生成）で発見**＝名前がマップに付き、領域の周り（半径＋1.0）のモヤが広めに晴れる。初回は「新発見！」。
- 暴走域はモヤが晴れれば名前が出る（危険は隠さない）。
- 描画はプロット領域を 92×80 のセルで覆う低解像度テクスチャ。4 段階に量子化し縁を市松で抜く（ドット絵の霧）。
  新しく晴れた点だけ差分で反映するので、毎フレームの再計算はしない。
- `MapExploration` は Resource なので `.tres` に保存できる＝セーブデータの一部にできる。

## 4. 温度＝縦軸の扱い

- マーカーの縦位置は**釜の温度**（`LabBench.vessel_temperature`）に毎フレーム追従する（`ReactionMap.temperature_to_y`）。
  熱源の天井より上には行けない（`set_heat_source`）。
- 素材の跳躍に縦成分があれば**反応熱**として釜の温度に押し上げ（下げ）として入り、火の温度へ戻っていく。
- 直火の薪入れは「炎が小さくなった（熾火）ときが好機」。燃え盛っている最中に入れると窒息する
  （`FireSim.is_ember()`、判定は火勢。燃料残量ではない）。

## 5. 既知の調整点

- 収率は経路長で決まるため、温度の上下動がそのまま経路長になり低く出やすい（例: 17〜19%）。
  温度の往復を経路長から軽くする、または「かき混ぜ・加水・蒸留」だけを経路長に数える案がある。
- 目標の位置（℃）は仮。希硫酸は直火で届く高さ（約 430℃ 中心）に置いてある。
- ノートの再生・委任量産は core にあるが、ラボ UI からは未接続。
